# ARCANA COUNTER

ヴァンガード「Persona 30th Anniversary」向けの非公式アルカナマーカーカウンター。Next.js 16 / React 19 / TypeScriptで実装しています。

## 公開（GitHub + Vercel）

GitHubリポジトリをVercelに連携し、GitHubへのpushを起点にビルド・公開する運用を想定しています。

1. このリポジトリをGitHubへpushします。
2. Vercelの「New Project」からGitHubを連携し、対象リポジトリをImportします。
3. Framework Presetが **Next.js**、Root Directoryがリポジトリのルートであることを確認します。Build Commandは `npm run build`、Output DirectoryはNext.jsの既定値を使用します。現在の実装に環境変数や外部データベースの設定は不要です。
4. Production Branchを `main` に設定してDeployします。
5. 発行された本番URLをiPhone・iPadのSafariで開き、カウント・表示設定・再読み込み後の復元を確認します。公開対象のユーザーがアクセスできることも確認してください。

連携後は、作業ブランチへのpushでPreview Deploymentを作成し、プレビューで確認した変更を `main` にマージしてpushすると本番へ反映されます。

利用時は同じ本番URLを開いてください。localStorageはURLのオリジン単位のため、プレビューURL・本番URL・独自ドメイン間でカウントや表示設定は共有されません。端末間の同期も行いません。

公式手順：[GitHub連携](https://vercel.com/docs/git/vercel-for-github) / [Gitリポジトリからのデプロイ](https://vercel.com/docs/git)

## ローカル開発

Node.js 22.18以降（推奨24）で実行してください。

```sh
npm ci
npm run dev
```

PCでは http://localhost:3000 を開きます。本番動作は `npm run build` → `npm start` で確認できます。

同じWi-FiのiPhone・iPadから開発中の画面を試す場合は `npm run dev -- --hostname 0.0.0.0` で起動し、Safariで `http://PCのLAN内IPv4アドレス:3000` を開きます。Windowsファイアウォールが接続を許可している必要があります。通常利用はVercelの本番URLを想定しています。

## 使い方

- 上部のエネルギーカウンターは0〜10。±1で調整、「チャージ ＋3」で加算（上限10）、「ブラスト −7」で消費します。7未満ではブラストできません。シリーズごとに自動保存し、旧保存データでは0から開始します。
- エネルギー欄の「リセット」はエネルギーだけを0に戻します。アルカナ一覧のリセットではエネルギーは残ります。ライド・ターン進行やドローは自動処理しません。
- エネルギーはライト／ダークボタンの下に配置。上段の対戦相手用は対面から読めるよう180度回転し、下段の自分用とは独立して操作・保存します。残量は10個のマーカーでも表示します。
- 「対戦相手を非表示／表示」で相手側を切り替えます。表示設定は自動保存され、非表示にしても相手の残量は残ります。
- 残量マーカーは1〜10の数字を表示し、タップ・クリックでその値を選べます。マーカー上をスライド・ドラッグして連続調整もできます。0にする場合は「−」またはリセットを使います。操作ボタンは「−／ブラスト −7／チャージ ＋3／＋」の順です。
- P3（青）・P4（黄）・P5（赤）を切り替え、＋／−で0〜3枚に増減します。背景やカードもシリーズ色に切り替わります。
- 画面上部の「ライト」「ダーク」で背景の明暗を切り替えます。
- カードには番号・日本語名と外国語のルビをまとめて表示します。P3/P4は英語、P5はフランス語です。
- 「表示設定」で使わないアルカナを非表示にできます。「すべて表示」で復帰できます。
- 非表示のカウントも保持され、合計・3枚そろった種類の集計に含まれます。
- 「リセット」→「0にリセット」で、選択中シリーズの非表示分を含めたカウントを0に戻します。表示設定・他シリーズのカウントは残ります。
- 保存データが不正なJSONやオブジェクト以外の場合、元データを上書きせず、その画面での自動保存を停止して警告します。保存を再開するには、このサイトのブラウザ保存データを削除して再読み込みしてください（全シリーズの保存内容が消えます）。
- オブジェクト内の不正なカウント・未知のIDは除外して保存し直します。複数タブで同時操作した場合は、最後の保存が優先されます。
- 選択シリーズ・表示モード・カウント・表示設定をlocalStorageへ自動保存します。別端末・別ブラウザ・別URLとは共有しません。ブラウザデータ削除で保存内容が消えます。

## アルカナ定義

[公式カードリスト（DZ-TBP02）](https://cf-vanguard.com/cardlist/cardsearch/?keyword=DZ-TBP02) のAR01〜AR47とユニットのアルカナ表記を参照しています（2026-10-25確認）。

- P3：愚者〜審判、永劫（22種類）
- P4：愚者〜審判、永劫、道化師（23種類）
- P5：愚者〜世界、信念、顧問官（24種類）

定義は `app/arcana.ts`。デッキで使用しない種類は表示設定で絞り込んでください。カード画像や公式ロゴは収録していません。

エネルギーの上限・チャージ・ブラストは[公式カードリスト「エネルギージェネレーター」（DZ-SD01/005）](https://cf-vanguard.com/cardlist/?cardno=DZ-SD01%2F005&expansion=259&view=image)を参照しています。

## 検証

```sh
npm run lint
node --test app/arcana.test.mjs
npm run build
```

データテストではシリーズ固有の定義、P5のフランス語表記、表示モードの保存・旧保存データとの互換性、型・範囲の不正値を検証します。
画面は44px以上の増減ボタン、2〜4列の可変レイアウト、モーダルのキャンセル初期フォーカスに対応しています。
Safari実機での動作は別途確認が必要です。オフライン起動・端末間同期には対応していません。
